# isobar-pr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `isobar-pr`, a zero-dependency TypeScript CLI + composite GitHub Action that runs isobar on a PR's merge base and head, diffs the two `graph.json` files, and posts a sticky PR comment, inline annotations, a job summary and an optional gate.

**Architecture:** A pure `diff/` layer turns two `GraphIndex` objects plus the PR's changed files into a `Report`; `report/` renders it to Markdown, workflow-command annotations and stable JSON; `run/` is the only impure layer (git worktree, `npx isobar`, orchestration) and is shared by the `compare` subcommand and `action.yml`. Spec: `docs/superpowers/specs/2026-10-22-isobar-pr-design.md`.

**Tech Stack:** TypeScript 5.9 strict, ESM, Node ≥ 20, esbuild (single committed `dist/cli.js`), vitest, zero runtime dependencies (isobar via `npx isobar@0.7.1`, GitHub via `gh`, git via `child_process`).

```ts
import { VERSION } from './version.js';

export interface Io {
  out(s: string): void;
  err(s: string): void;
  env: NodeJS.ProcessEnv;
}

export interface ParsedArgs {
  command: string | undefined;
  positional: string[];
  flags: Record<string, string | true>;
}

const BOOLEAN_FLAGS = new Set(['gate-output', 'report-uncalled-routes', 'keep-temp', 'help', 'version']);
const COMMANDS = new Set(['diff', 'compare']);

export function parseArgs(argv: string[]): ParsedArgs {
  const parsed: ParsedArgs = { command: undefined, positional: [], flags: {} };
  for (let i = 0; i < argv.length; i++) {
    const arg = argv[i]!;
    if (arg.startsWith('--')) {
      const eq = arg.indexOf('=');
      if (eq > 0) {
        parsed.flags[arg.slice(2, eq)] = arg.slice(eq + 1);
        continue;
      }
      const key = arg.slice(2);
      const next = argv[i + 1];
      if (next !== undefined && !next.startsWith('--') && !BOOLEAN_FLAGS.has(key)) {
        parsed.flags[key] = next;
        i++;
      } else {
        parsed.flags[key] = true;
      }
    } else if (parsed.command === undefined && COMMANDS.has(arg)) {
      parsed.command = arg;
    } else {
      parsed.positional.push(arg);
    }
  }
  return parsed;
}

export const USAGE = `Usage: isobar-pr <command> [options]

Commands:
  diff      Diff two graph.json files:  --base b.json --head h.json --changes files.txt [--hunks diff.txt]
  compare   Run isobar on merge-base and head, then diff:  [dir] [--base-ref main] [--head-ref HEAD]

Shared options:
  --format markdown|json|annotations|all   (default markdown; "all" needs --out)
  --out DIR                                 write report.md, report.json, annotations.txt
  --fail-on none|serious-security|limit-crossed|any
  --gate-output                             always exit 0; write gate= and summary= to $GITHUB_OUTPUT
  --report-uncalled-routes                  also report new routes with no caller in this repo

compare options:
  --isobar-version X.Y.Z   exact isobar version (default 0.7.1)
  --scope DIR              only analyze this sub-folder
  --keep-temp              keep the temporary worktree and graphs

Exit codes: 0 ok · 1 gate failed · 2 usage or environment · 3 isobar or git failure
`;

export function defaultIo(): Io {
  return {
    out: (s) => { process.stdout.write(s); },
    err: (s) => { process.stderr.write(s); },
    env: process.env,
  };
}

export async function main(argv: string[], io: Io = defaultIo()): Promise<number> {
  const args = parseArgs(argv);
  if (args.flags['version'] === true) {
    io.out(`${VERSION}\n`);
    return 0;
  }
  if (args.flags['help'] === true || args.command === undefined) {
    io.out(USAGE);
    return args.command === undefined && args.flags['help'] !== true ? 2 : 0;
  }
  io.err(`isobar-pr: command "${args.command}" is not implemented yet\n`);
  return 2;
}
```

```ts
import { readFileSync } from 'node:fs';
import type { GraphV3 } from './types.js';

export class SchemaError extends Error {
  override name = 'SchemaError';
}

export class VersionMismatchError extends Error {
  override name = 'VersionMismatchError';
  constructor(base: string, head: string) {
    super(`isobar versions differ: base ${base}, head ${head}. Pin one version with --isobar-version.`);
  }
}

export function parseGraph(text: string, label: string): GraphV3 {
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch (e) {
    throw new SchemaError(`${label}: not valid JSON (${(e as Error).message})`);
  }
  if (typeof data !== 'object' || data === null) throw new SchemaError(`${label}: graph.json is not an object`);
  const g = data as Partial<GraphV3>;
  if (g.schema_version !== 3) {
    throw new SchemaError(`${label}: expected graph.json schema_version 3, got ${String(g.schema_version)}`);
  }
  if (typeof g.files !== 'object' || g.files === null) throw new SchemaError(`${label}: graph.json has no "files" map`);
  if (typeof g.tool_version !== 'string' || g.tool_version === '') {
    throw new SchemaError(`${label}: graph.json has no "tool_version"`);
  }
  return g as GraphV3;
}

export function loadGraph(path: string, label = path): GraphV3 {
  return parseGraph(readFileSync(path, 'utf8'), label);
}
```

```ts
import type { ConventionPattern, GraphFunction, GraphV3, Hotspot, SecurityWarning } from './types.js';
import { DEFAULT_LIMITS } from './types.js';

export interface FunctionRef {
  file: string;
  name: string;
  /** 0-based position among functions with the same name in the same file, in source order. */
  ordinal: number;
  fn: GraphFunction;
}

export interface GraphIndex {
  graph: GraphV3;
  toolVersion: string;
  limits: Record<string, number>;
  functionsByFile: Map<string, FunctionRef[]>;
  hotspotsByFile: Map<string, Hotspot>;
  patternsById: Map<string, ConventionPattern>;
  warningsByKey: Map<string, SecurityWarning>;
  cycles: string[][];
  testImportersByFile: Map<string, number>;
  /** True when the repo both serves routes and makes HTTP calls, i.e. calls can be matched within it. */
  httpActive: boolean;
}

export function warningKey(file: string, text: string): string {
  return `${file}\u0000${text}`;
}

export function buildIndex(graph: GraphV3): GraphIndex {
  const functionsByFile = new Map<string, FunctionRef[]>();
  const testImportersByFile = new Map<string, number>();
  let callCount = 0;

  for (const [file, entry] of Object.entries(graph.files)) {
    const seen = new Map<string, number>();
    const refs: FunctionRef[] = [];
    for (const fn of entry.functions ?? []) {
      const ordinal = seen.get(fn.name) ?? 0;
      seen.set(fn.name, ordinal + 1);
      refs.push({ file, name: fn.name, ordinal, fn });
    }
    functionsByFile.set(file, refs);
    const tests = (entry.imported_by ?? []).filter((p) => graph.files[p]?.kind === 'test').length;
    testImportersByFile.set(file, tests);
    callCount += (entry.calls ?? []).length;
  }

  const hotspotsByFile = new Map((graph.hotspots ?? []).map((h) => [h.file, h] as const));
  const patternsById = new Map((graph.conventions?.patterns ?? []).map((p) => [p.id, p] as const));
  const warningsByKey = new Map(
    (graph.security?.warnings ?? []).map((w) => [warningKey(w.file, w.text), w] as const),
  );
  const routeCount = graph.http?.routes?.length ?? 0;

  return {
    graph,
    toolVersion: graph.tool_version,
    limits: { ...DEFAULT_LIMITS, ...(graph.complexity?.limits ?? {}) },
    functionsByFile,
    hotspotsByFile,
    patternsById,
    warningsByKey,
    cycles: graph.cycles ?? [],
    testImportersByFile,
    httpActive: routeCount > 0 && callCount > 0,
  };
}
```

```ts
export interface Range {
  start: number;
  end: number;
}

export interface Changes {
  /** Head-side paths changed by the PR (added, copied, modified, renamed, type-changed). */
  changed: Set<string>;
  /** new path → old path for renames. */
  renames: Map<string, string>;
  /** Added-side line ranges per head path, from `git diff -U0`. Undefined when not supplied. */
  hunks?: Map<string, Range[]>;
}

/** Parses `git diff --name-status -M BASE HEAD` (statuses A, C, D, M, R, T; D rows land in `deleted` — A25). */
export function parseChanges(text: string): Changes {
  const changed = new Set<string>();
  const renames = new Map<string, string>();
  for (const raw of text.split('\n')) {
    const line = raw.replace(/\r$/, '');
    if (line.trim() === '') continue;
    const parts = line.split('\t');
    const status = parts[0] ?? '';
    if (status.startsWith('R') || status.startsWith('C')) {
      const from = parts[1];
      const to = parts[2];
      if (!from || !to) continue;
      changed.add(to);
      if (status.startsWith('R')) renames.set(to, from);
    } else if (status === 'D') {
      continue;
    } else {
      const path = parts[1];
      if (path) changed.add(path);
    }
  }
  return { changed, renames };
}

/** Parses `git diff -U0 BASE HEAD` into added-side line ranges per file. */
export function parseHunks(text: string): Map<string, Range[]> {
  const hunks = new Map<string, Range[]>();
  let current: string | undefined;
  for (const raw of text.split('\n')) {
    const line = raw.replace(/\r$/, '');
    if (line.startsWith('+++ ')) {
      const target = line.slice(4);
      current = target === '/dev/null' ? undefined : target.replace(/^b\//, '');
      continue;
    }
    if (current === undefined || !line.startsWith('@@')) continue;
    const m = /^@@ -\d+(?:,\d+)? \+(\d+)(?:,(\d+))? @@/.exec(line);
    if (!m) continue;
    const start = Number(m[1]);
    const count = m[2] === undefined ? 1 : Number(m[2]);
    if (count === 0) continue;
    const list = hunks.get(current) ?? [];
    list.push({ start, end: start + count - 1 });
    hunks.set(current, list);
  }
  return hunks;
}

export function filterChanges(changes: Changes, scope?: string): Changes {
  if (!scope) return changes;
  const prefix = scope.replace(/\/+$/, '') + '/';
  const inScope = (p: string) => p.startsWith(prefix);
  return {
    changed: new Set([...changes.changed].filter(inScope)),
    renames: new Map([...changes.renames].filter(([to]) => inScope(to))),
    hunks: changes.hunks ? new Map([...changes.hunks].filter(([p]) => inScope(p))) : undefined,
  };
}

export function overlaps(ranges: Range[] | undefined, start: number, end: number): boolean {
  if (!ranges) return false;
  return ranges.some((r) => r.start <= end && r.end >= start);
}
```

```ts
import type { GraphIndex } from '../graph/index.js';
import type { FailOn } from '../report/types.js';
import type { Changes } from './changes.js';
import { overlaps } from './changes.js';

export interface DiffOptions {
  failOn: FailOn;
  reportUncalledRoutes: boolean;
  baseRef: string;
  baseSha: string;
  headSha: string;
}

export interface DiffContext {
  base: GraphIndex;
  head: GraphIndex;
  changes: Changes;
  opts: DiffOptions;
  /** Changed head paths, sorted. */
  changed: string[];
  /** The same files in base path space (renames applied). */
  changedBase: Set<string>;
  basePath(headPath: string): string;
  isChanged(headPath: string): boolean;
  /** Undefined when hunks are unknown; true for a file-level question when hunks are known. */
  inDiff(file: string, line?: number): boolean | undefined;
  inDiffRange(file: string, start: number, end: number): boolean | undefined;
}

export function createContext(base: GraphIndex, head: GraphIndex, changes: Changes, opts: DiffOptions): DiffContext {
  const changed = [...changes.changed].sort();
  const basePath = (p: string): string => changes.renames.get(p) ?? p;
  const changedBase = new Set(changed.map(basePath));
  const inDiffRange = (file: string, start: number, end: number): boolean | undefined =>
    changes.hunks ? overlaps(changes.hunks.get(file), start, end) : undefined;
  return {
    base,
    head,
    changes,
    opts,
    changed,
    changedBase,
    basePath,
    isChanged: (p) => changes.changed.has(p),
    inDiff: (file, line) => (line === undefined ? (changes.hunks ? true : undefined) : inDiffRange(file, line, line)),
    inDiffRange,
  };
}
```

```ts
export const FAIL_ON_VALUES: readonly FailOn[] = ['none', 'serious-security', 'limit-crossed', 'any'];

export function isFailOn(v: string): v is FailOn {
  return (FAIL_ON_VALUES as readonly string[]).includes(v);
}

export function gate(findings: Finding[], failOn: FailOn): 'pass' | 'fail' {
  switch (failOn) {
    case 'none':
      return 'pass';
    case 'serious-security':
      return findings.some((f) => (f.kind === 'security-new' || f.kind === 'security-grew') && f.severity === 'serious')
        ? 'fail'
        : 'pass';
    case 'limit-crossed':
      return findings.some((f) => f.kind === 'function-regression' && Array.isArray(f.data['metrics']) && f.data['metrics'].length > 0)
        ? 'fail'
        : 'pass';
    case 'any':
      return findings.some((f) => f.severity !== 'info' && f.severity !== 'improved') ? 'fail' : 'pass';
```

```ts
export const KIND_ORDER: readonly FindingKind[] = [
  'config-changed',
  'function-regression',
  'hotspot-touched',
  'convention-broken',
  'convention-weakened',
  'security-new',
  'security-grew',
  'cycle-new',
  'cycle-grew',
  'http-unmatched-call',
  'http-uncalled-route',
  'http-info',
  'unresolved-new',
  'function-improved',
  'cycle-broken',

export function sortFindings(findings: Finding[]): Finding[] {
  const key = (f: Finding): number[] => [KIND_ORDER.indexOf(f.kind), f.inDiff === false ? 1 : 0, SEVERITY_ORDER[f.severity]];
  return [...findings].sort((a, b) => {
    const ka = key(a);
    const kb = key(b);
    for (let i = 0; i < ka.length; i++) if (ka[i] !== kb[i]) return ka[i]! - kb[i]!;
    return a.file.localeCompare(b.file) || (a.line ?? 0) - (b.line ?? 0) || a.title.localeCompare(b.title);
  });
}
```

`src/diff/functions.ts`:

```ts
import type { FunctionRef } from '../graph/index.js';
import type { GraphFunction, RefactorIssue } from '../graph/types.js';
import { code } from '../report/text.js';
import type { Finding, Severity } from '../report/types.js';
import type { DiffContext } from './context.js';

const SUPERSCRIPT: Record<string, number> = { '²': 2, '³': 3, '⁴': 4 };

/**
 * Ordinal growth class of an isobar time label, or undefined when the label cannot be read.
 * 0 O(1) · 1 O(log n) · 2 linear · 3 O(n log n) · 4 quadratic (n², n·m) · 5 cubic or worse (n³, n·m·k, n·m², "or more") · 6 O(2ⁿ).
 */
export function timeRank(time: string | undefined): number | undefined {
  if (time === undefined) return undefined;
  const inner = time.trim().replace(/^O\((.*)\)$/, '$1').trim();
  if (inner === '1') return 0;
  if (inner === 'log n') return 1;
  if (inner === 'n log n') return 3;
  if (/^2(\^n|ⁿ)$/.test(inner)) return 6;
  if (/or more$/.test(inner)) return 5;
  let degree = 0;
  for (const factor of inner.split('·')) {
    const m = /^([a-z])(?:\^(\d+)|([²³⁴]))?$/.exec(factor.trim());
    if (!m) return undefined;
    degree += m[2] !== undefined ? Number(m[2]) : m[3] !== undefined ? (SUPERSCRIPT[m[3]] ?? 1) : 1;
  }
  if (degree === 0) return undefined;
  return degree === 1 ? 2 : degree === 2 ? 4 : 5;
}

const METRIC_LABEL: Record<string, string> = {
  cognitive: 'cognitive',
  cyclomatic: 'cyclomatic',
  nesting: 'nesting',
  lines: 'lines',
  params: 'parameters',
};

export interface MetricDelta {
  name: string;
  limit: number;
  base: number | null;
  head: number | null;
}

export interface TimeDelta {
  base: string;
  head: string;
  why: string[];
}

export interface IssueDelta {
  kind: string;
  severity: string;
  title: string;
  how: string;
  why: string;
}

function metricValue(fn: GraphFunction | undefined, name: string): number | null {
  if (!fn) return null;
  const v = (fn as unknown as Record<string, unknown>)[name];
  return typeof v === 'number' ? v : null;
}

const rank = timeRank;

function toIssue(i: RefactorIssue): IssueDelta {
  return { kind: i.kind, severity: i.severity, title: i.title, how: i.how ?? '', why: i.why ?? '' };
}

function fmt(v: number | null): string {
  return v === null ? '–' : String(v);
}

function describeRegression(metrics: MetricDelta[], time: TimeDelta | undefined, isNew: boolean): string {
  const parts = metrics.map(
    (m) => `${METRIC_LABEL[m.name] ?? m.name} ${isNew ? '' : `${fmt(m.base)} → `}**${fmt(m.head)}** (limit ${m.limit})`,
  );
  if (time) parts.push(`${time.base} → **${time.head}**${time.why.length ? ` (${time.why[0]})` : ''}`);
  if (parts.length === 0) parts.push('new performance issue');
  return parts.join(', ') + (isNew ? ' · new' : '');
}

function describeImprovement(metrics: MetricDelta[], time: TimeDelta | undefined, gone: IssueDelta[]): string {
  const parts = metrics.map((m) => `${METRIC_LABEL[m.name] ?? m.name} ${fmt(m.base)} → ${fmt(m.head)}, now within limit ${m.limit}`);
  if (time) parts.push(`${time.base} → ${time.head}`);
  for (const g of gone) parts.push(`${g.title} resolved`);
  return parts.join(', ');
}

function compareFunction(ctx: DiffContext, file: string, head: FunctionRef, base: FunctionRef | undefined): Finding[] {
  const limits = ctx.head.limits;
  const headOver = new Set(head.fn.over ?? []);
  const baseOver = new Set(base?.fn.over ?? []);
  const delta = (name: string): MetricDelta => ({
    name,
    limit: limits[name] ?? 0,
    base: metricValue(base?.fn, name),
    head: metricValue(head.fn, name),
  });
  const crossed = [...headOver].filter((m) => !baseOver.has(m)).sort().map(delta);
  const left = [...baseOver].filter((m) => !headOver.has(m)).sort().map(delta);

  const headRank = rank(head.fn.time);
  const baseRank = rank(base?.fn.time);
  const timeUp = headRank !== undefined && baseRank !== undefined && headRank > baseRank;
  const timeDown = headRank !== undefined && baseRank !== undefined && headRank < baseRank;
  const time: TimeDelta | undefined =
    timeUp || timeDown
      ? { base: base!.fn.time!, head: head.fn.time!, why: (head.fn.time_why ?? []).map((w) => `L${w.line}: ${w.text}`) }
      : undefined;

  const baseKinds = new Set((base?.fn.refactor ?? []).map((i) => i.kind));
  const headKinds = new Set((head.fn.refactor ?? []).map((i) => i.kind));
  const newIssues = (head.fn.refactor ?? []).filter((i) => !baseKinds.has(i.kind)).map(toIssue);
  const goneIssues = (base?.fn.refactor ?? []).filter((i) => !headKinds.has(i.kind)).map(toIssue);

  const line = head.fn.line;
  const end = head.fn.end_line ?? line;
  const basePath = ctx.basePath(file);
  const common = {
    file,
    line,
    renamedFrom: basePath !== file ? basePath : undefined,
    inDiff: ctx.inDiffRange(file, line, end),
  };
  const out: Finding[] = [];

  if (crossed.length > 0 || timeUp || newIssues.length > 0) {
    const severity: Severity =
      timeUp || newIssues.some((i) => i.severity === 'serious' || i.severity === 'high') ? 'high' : 'medium';
    out.push({
      kind: 'function-regression',
      severity,
      ...common,
      title: `${code(head.name)} — ${describeRegression(crossed, timeUp ? time : undefined, base === undefined)}`,
      advice: newIssues[0]?.how || undefined,
      data: {
        name: head.name,
        ordinal: head.ordinal,
        metrics: crossed,
        time: timeUp ? time : null,
        issues: newIssues,
        isNew: base === undefined,
      },
    });
  }

  if (base !== undefined && (left.length > 0 || timeDown || goneIssues.length > 0)) {
    out.push({
      kind: 'function-improved',
      severity: 'improved',
      ...common,
      title: `${code(head.name)} — ${describeImprovement(left, timeDown ? time : undefined, goneIssues)}`,
      data: { name: head.name, ordinal: head.ordinal, metrics: left, time: timeDown ? time : null, issues: goneIssues },
    });
  }
  return out;
}

function groupByName(refs: FunctionRef[]): Map<string, FunctionRef[]> {
  const groups = new Map<string, FunctionRef[]>();
  for (const r of refs) {
    const list = groups.get(r.name) ?? [];
    list.push(r);
    groups.set(r.name, list);
  }
  return groups;
}

function approximate(ctx: DiffContext, file: string, name: string, heads: FunctionRef[], bases: FunctionRef[]): Finding[] {
  const overCount = (refs: FunctionRef[]) => refs.filter((r) => (r.fn.over ?? []).length > 0).length;
  const baseCount = overCount(bases);
  const headCount = overCount(heads);
  if (baseCount === headCount) return [];
  const first = heads[0]!;
  const common = {
    file,
    line: first.fn.line,
    inDiff: ctx.inDiffRange(file, first.fn.line, first.fn.end_line ?? first.fn.line),
    title: `${code(name)} ×${heads.length} — ${headCount} over a limit, was ${baseCount}`,
    detail: 'approximate match: the number of functions with this name changed',
    data: { name, metrics: [], issues: [], time: null, approximate: true, overBase: baseCount, overHead: headCount },
  };
  return headCount > baseCount
    ? [{ kind: 'function-regression', severity: 'medium', ...common }]
    : [{ kind: 'function-improved', severity: 'improved', ...common }];
}

export function functionFindings(ctx: DiffContext): Finding[] {
  const out: Finding[] = [];
  for (const file of ctx.changed) {
    const headRefs = ctx.head.functionsByFile.get(file);
    if (!headRefs) continue;
    const baseRefs = ctx.base.functionsByFile.get(ctx.basePath(file)) ?? [];
    const baseGroups = groupByName(baseRefs);
    for (const [name, heads] of groupByName(headRefs)) {
      const bases = baseGroups.get(name) ?? [];
      if (bases.length === 0 || bases.length === heads.length) {
        heads.forEach((h, i) => out.push(...compareFunction(ctx, file, h, bases[i])));
      } else {
        out.push(...approximate(ctx, file, name, heads, bases));
      }
    }
  }
  return out;
}
```

```ts
import type { Finding } from '../report/types.js';
import type { DiffContext } from './context.js';

export function hotspotFindings(ctx: DiffContext): Finding[] {
  const out: Finding[] = [];
  for (const file of ctx.changed) {
    const basePath = ctx.basePath(file);
    const h = ctx.base.hotspotsByFile.get(basePath);
    if (!h) continue;
    const tests = ctx.base.testImportersByFile.get(basePath) ?? 0;
    out.push({
      kind: 'hotspot-touched',
      severity: tests > 0 ? 'low' : 'medium',
      file,
      renamedFrom: basePath !== file ? basePath : undefined,
      inDiff: true,
      title: `base hotspot rank **${h.rank}** (${h.commits} commits, cognitive ${h.cognitive}), imported by ${tests} test${tests === 1 ? '' : 's'}`,
      advice: 'Keep changes small and tested.',
      data: { rank: h.rank, score: h.score, commits: h.commits, cognitive: h.cognitive, testImporters: tests },
    });
  }
  return out;
}
```

```ts
import { code } from '../report/text.js';
import type { Finding } from '../report/types.js';
import type { DiffContext } from './context.js';

export function conventionFindings(ctx: DiffContext): Finding[] {
  const out: Finding[] = [];
  for (const [id, headPattern] of ctx.head.patternsById) {
    const basePattern = ctx.base.patternsById.get(id);
    if (!basePattern) continue;
    if (headPattern.strength !== 'rule' && headPattern.strength !== 'mostly') continue;

    const baseExceptions = new Set(basePattern.exceptions ?? []);
    const newExceptions = (headPattern.exceptions ?? [])
      .filter((f) => ctx.isChanged(f) && !baseExceptions.has(ctx.basePath(f)))
      .sort();
    for (const file of newExceptions) {
      out.push({
        kind: 'convention-broken',
        severity: headPattern.strength === 'rule' ? 'medium' : 'low',
        file,
        inDiff: true,
        title: `**${headPattern.title}** (${headPattern.follow} of ${headPattern.total} followed)`,
        detail: 'breaks it.',
        advice: headPattern.example ? `Copy ${code(headPattern.example)} instead.` : undefined,
        data: {
          patternId: id,
          strength: headPattern.strength,
          follow: headPattern.follow,
          total: headPattern.total,
          example: headPattern.example ?? null,
          rule: headPattern.rule,
        },
      });
    }

    if (basePattern.strength === 'rule' && headPattern.strength === 'mostly') {
      const touched = (headPattern.exceptions ?? []).filter((f) => ctx.isChanged(f)).sort();

            from: 'rule',
            to: 'mostly',
            baseFollow: basePattern.follow,
            baseTotal: basePattern.total,
            headFollow: headPattern.follow,
            headTotal: headPattern.total,
          },
        });
      }
    }
  }
  return out;
```

```ts
import type { Finding, Severity } from '../report/types.js';
import type { DiffContext } from './context.js';

export function securityFindings(ctx: DiffContext): Finding[] {
  const out: Finding[] = [];
  for (const w of ctx.head.warningsByKey.values()) {
    if (!ctx.isChanged(w.file)) continue;
    const baseWarning = ctx.base.warningsByKey.get(warningKey(ctx.basePath(w.file), w.text));
    const headLines = w.lines && w.lines.length > 0 ? w.lines : [w.line];
    const severity: Severity = w.level === 'serious' ? 'serious' : 'medium';
    const inHunk = headLines.filter((l) => ctx.inDiffRange(w.file, l, l) === true);

    if (!baseWarning) {
      const line = inHunk[0] ?? headLines[0]!;
      out.push({
        kind: 'security-new',
        severity,
        file: w.file,
        line,
        inDiff: ctx.inDiff(w.file, line),
        title: `**${w.level}** — ${w.text}`,
        detail: w.code ? code(w.code.trim()) : undefined,
        data: { level: w.level, text: w.text, lines: headLines, code: w.code ?? null },
      });
      continue;
    }

    const baseCount = baseWarning.lines && baseWarning.lines.length > 0 ? baseWarning.lines.length : 1;
    if (headLines.length > baseCount) {
      const added = headLines.length - baseCount;
      const line = inHunk[0] ?? headLines[headLines.length - 1]!;
      out.push({
        kind: 'security-grew',
        severity,
        file: w.file,
        line,
        inDiff: ctx.inDiff(w.file, line),
        title: `**${w.level}** — ${w.text}`,
        detail: `${added} more occurrence${added === 1 ? '' : 's'} (${baseCount} → ${headLines.length})${inHunk.length ? `, at L${inHunk.join(', L')}` : ''}`,
        data: { level: w.level, text: w.text, added, lines: inHunk, code: w.code ?? null },
      });
    }
  }
  return out;
}
```

```ts
import { code } from '../report/text.js';
import type { Finding } from '../report/types.js';
import type { DiffContext } from './context.js';

function cycleId(files: string[]): string {
  return [...files].sort().join('\n');
}

export function cycleFindings(ctx: DiffContext): Finding[] {
  const out: Finding[] = [];
  const baseCycles = ctx.base.cycles.map((files) => ({ id: cycleId(files), set: new Set(files) }));
  const baseIds = new Set(baseCycles.map((c) => c.id));
  const headCycles = ctx.head.cycles.map((files) => {
    const mapped = files.map(ctx.basePath);
    return { files, id: cycleId(mapped), set: new Set(mapped) };
  });

  for (const h of headCycles) {
    const touched = h.files.filter((f) => ctx.isChanged(f)).sort();
    if (touched.length === 0 || baseIds.has(h.id)) continue;
    const file = touched[0]!;
    const sortedFiles = [...h.files].sort();
    const grown = baseCycles.find((b) => b.set.size < h.set.size && [...b.set].every((f) => h.set.has(f)));
    const shrunk = baseCycles.some((b) => b.set.size > h.set.size && [...h.set].every((f) => b.set.has(f)));
    if (grown) {
      const added = h.files.filter((f) => !grown.set.has(ctx.basePath(f))).sort();
      out.push({
        kind: 'cycle-grew',
        severity: 'high',
        file,
        inDiff: true,
        title: `circular import grew to ${h.files.length} files (+${added.length}): ${added.map(code).join(', ')}`,
        data: { files: sortedFiles, added },
      });
    } else if (shrunk) {
      // A remnant of a larger base cycle: reported from the base side as a shrink, below.
      continue;
    } else {
      out.push({
        kind: 'cycle-new',
        severity: 'high',
        file,
        inDiff: true,
        title: `new circular import across ${h.files.length} files: ${sortedFiles.map(code).join(' → ')}`,
        data: { files: sortedFiles },
      });
    }
  }

  for (const b of baseCycles) {
    const touched = [...b.set].filter((f) => ctx.changedBase.has(f)).sort();
    if (touched.length === 0) continue;
    const survives = headCycles.some((h) => [...b.set].every((f) => h.set.has(f)));
    if (survives) continue;
    const remnant = headCycles.find((h) => h.set.size < b.set.size && [...h.set].every((f) => b.set.has(f)));
    const headFile = ctx.changed.find((f) => ctx.basePath(f) === touched[0]) ?? touched[0]!;
    out.push({
      kind: 'cycle-broken',
      severity: 'improved',
      file: headFile,
      inDiff: true,
      title: remnant
        ? `circular import shrank from ${b.set.size} to ${remnant.set.size} files`
        : `circular import broken (${b.set.size} files)`,
      data: { files: [...b.set].sort(), shrankTo: remnant ? [...remnant.files].sort() : null },
    });
  }
  return out;
}
```

```ts
        data: { staticBase, staticHead, dynamicBase, dynamicHead },
      });
    }
    return out;
  }

  for (const file of ctx.changed) {
    const head = ctx.head.graph.files[file];
    if (!head) continue;
    const base = ctx.base.graph.files[ctx.basePath(file)];
    const baseUnmatched = new Set((base?.calls ?? []).filter(isUnmatched).map(callKey));
    for (const c of (head.calls ?? []).filter(isUnmatched)) {
      if (baseUnmatched.has(callKey(c))) continue;
      out.push({
        kind: 'http-unmatched-call',
        severity: 'medium',
        file,
        line: c.line,
        inDiff: ctx.inDiff(file, c.line),
        title: `${code(callKey(c))} has no matching route`,
        data: { method: c.method, path: c.path },
      });
    }
    if (ctx.opts.reportUncalledRoutes) {
      const baseRoutes = new Set((base?.serves ?? []).map((r) => `${r.method} ${r.path}`));
      for (const r of head.serves ?? []) {
        const key = `${r.method} ${r.path}`;
        if ((r.callers ?? []).length > 0 || baseRoutes.has(key)) continue;
        out.push({
          kind: 'http-uncalled-route',
          severity: 'low',
          file,
          line: r.line,
          inDiff: ctx.inDiff(file, r.line),
          title: `${code(key)} is a new route no client in this repo calls`,
          data: { method: r.method, path: r.path },
        });
      }
    }
  }
  return out;
}
```

```ts
  cognitive: number;
  over: number;
  exceptions: number;
  serious: number;
  advisory: number;
  cycles: number;
  unmatched: number;
}

function totals(idx: GraphIndex, files: string[]): SideTotals {
  const set = new Set(files);
  const t: SideTotals = { cognitive: 0, over: 0, exceptions: 0, serious: 0, advisory: 0, cycles: 0, unmatched: 0 };
  for (const f of files) {
    const entry = idx.graph.files[f];
    if (!entry) continue;
    t.cognitive += entry.complexity?.cognitive ?? 0;
    t.over += (entry.functions ?? []).filter((fn) => (fn.over ?? []).length > 0).length;
    t.unmatched += (entry.calls ?? []).filter((c) => !c.dynamic && c.path !== null && !c.target && !c.external).length;
  }
  for (const w of idx.warningsByKey.values()) {
    if (!set.has(w.file)) continue;
    const n = w.lines && w.lines.length > 0 ? w.lines.length : 1;
    if (w.level === 'serious') t.serious += n;
    else t.advisory += n;
  }
  for (const p of idx.patternsById.values()) t.exceptions += (p.exceptions ?? []).filter((f) => set.has(f)).length;
  t.cycles = idx.cycles.filter((c) => c.some((f) => set.has(f))).length;
  return t;
}
```

```ts
  if (cognitive && cognitive.delta !== '0') parts.push(`${cognitive.delta} cognitive across ${plural(n, 'changed file')}`);
  const regressions = count('function-regression');
  if (regressions) parts.push(`${plural(regressions, 'function')} crossed a limit or got slower`);
  const hotspots = count('hotspot-touched');
  if (hotspots) parts.push(`${plural(hotspots, 'hotspot')} touched`);
  const conventions = count('convention-broken', 'convention-weakened');
  if (conventions) parts.push(`${plural(conventions, 'convention')} broken`);
  const security = report.findings.filter((f) => f.kind === 'security-new' || f.kind === 'security-grew');
  if (security.length) {
    const serious = security.filter((f) => f.severity === 'serious').length;
    parts.push(`${plural(security.length, 'security warning')}${serious ? ` (${serious} serious)` : ''}`);
  }
  const cycles = count('cycle-new', 'cycle-grew');
  if (cycles) parts.push(plural(cycles, 'circular import'));
  const http = count('http-unmatched-call', 'http-uncalled-route');
  if (http) parts.push(`${plural(http, 'call')} with no route`);
  const improved = count('function-improved', 'cycle-broken');
  if (improved) parts.push(`${improved} improved`);
  return parts.length ? parts.join(' · ') : `No pressure change in ${plural(n, 'changed file')}`;
}

function renderFinding(f: Finding): string {
  let line: string;
  if (f.kind === 'function-regression' || f.kind === 'function-improved') {
    line = `- ${code(f.file)} › ${f.title}${f.line !== undefined ? ` · L${f.line}` : ''}`;
  } else if (f.kind === 'convention-broken' || f.kind === 'convention-weakened') {
    line = `- ${f.title} — ${code(f.file)}${f.detail ? ` ${f.detail}` : ''}`;
  } else if (f.kind === 'http-info' || f.kind === 'config-changed') {
    line = `- ${f.title}`;
  } else {
    const loc = f.line !== undefined ? `${f.file}:${f.line}` : f.file;
    line = `- ${code(loc)} — ${f.title}${f.detail ? ` — ${f.detail}` : ''}`;
  }
  if (f.renamedFrom) line += ` (renamed from ${code(f.renamedFrom)})`;
  if (f.inDiff === false) line += ' _(outside the diff)_';
  if (f.advice) line += `\n  ↳ ${f.advice}${f.kind === 'function-regression' ? ' *(isobar refactor guide)*' : ''}`;
  return line;
}

function renderSection(heading: string, items: Finding[]): string {
  const shown = items.slice(0, PER_SECTION);
  const rest = items.slice(PER_SECTION);
  let out = `### ${heading}\n${shown.map(renderFinding).join('\n')}\n`;
  if (rest.length) out += `<details><summary>and ${rest.length} more</summary>\n\n${rest.map(renderFinding).join('\n')}\n\n</details>\n`;
  return out;
}

function shortSha(sha: string): string {
  return sha.length > 7 ? sha.slice(0, 7) : sha || '?';
}

export function renderMarkdown(report: Report, extra: { durationMs?: number } = {}): string {
  const out: string[] = [MARKER, '## 🌀 isobar-pr · pressure delta', '', headline(report), ''];
  if (report.meta.analyzedChangedFiles === 0) return out.join('\n') + '\n';

  const banner = report.findings.find((f) => f.kind === 'config-changed');
  if (banner) out.push(`> ⚠️ ${banner.title}`, '');

  if (report.summary.length) {
    out.push('| Signal (changed files only) | Base | Head | Δ |', '|---|---|---|---|');
    for (const r of report.summary) out.push(`| ${cell(r.label)} | ${cell(r.base)} | ${cell(r.head)} | ${cell(r.delta)} |`);
    out.push('');
  }

  for (const s of SECTIONS) {
    const items = report.findings.filter((f) => s.kinds.includes(f.kind));
    if (items.length) out.push(renderSection(s.heading, items));
  }

  const bits = [`isobar ${report.meta.toolVersion}`, `base ${shortSha(report.meta.baseSha)}`, `head ${shortSha(report.meta.headSha)}`];
  if (extra.durationMs !== undefined) bits.push(`${(extra.durationMs / 1000).toFixed(1)} s`);
  const pre = report.preExisting;
  out.push(`<details><summary>Pre-existing in changed files (${pre.length}) · ${bits.join(' · ')}</summary>`, '');
  out.push(
    pre.length
      ? pre.map((p) => `- ${code(p.line !== undefined ? `${p.file}:${p.line}` : p.file)} — ${p.text}`).join('\n')
      : '_Nothing pre-existing in the changed files._',
  );
  out.push('', '</details>', '');
  return out.join('\n');
}

export function truncateComment(markdown: string, limit = COMMENT_LIMIT): { text: string; truncated: boolean } {
  if (markdown.length <= limit) return { text: markdown, truncated: false };
  const note = '\n\n_Comment truncated. The full report is in the job summary and `report.json`._\n';
  return { text: markdown.slice(0, limit - note.length) + note, truncated: true };
}
```

```ts
import { plain } from './text.js';
import type { Report, Severity } from './types.js';
import { SEVERITY_ORDER } from './types.js';

type Level = 'error' | 'warning' | 'notice';

const LEVEL: Partial<Record<Severity, Level>> = { serious: 'error', high: 'warning', medium: 'warning', low: 'notice' };
const MAX_PER_LEVEL = 10;

function escapeProperty(s: string): string {
  return s.replace(/%/g, '%25').replace(/\r/g, '%0D').replace(/\n/g, '%0A').replace(/:/g, '%3A').replace(/,/g, '%2C');
}

function escapeData(s: string): string {
  return s.replace(/%/g, '%25').replace(/\r/g, '%0D').replace(/\n/g, '%0A');
}

/** Workflow-command lines. Only in-diff findings with a line; at most 10 per level, highest severity first. */
export function renderAnnotations(report: Report): string[] {
  const counts: Record<Level, number> = { error: 0, warning: 0, notice: 0 };
  const out: string[] = [];
  const bySeverity = [...report.findings].sort((a, b) => SEVERITY_ORDER[a.severity] - SEVERITY_ORDER[b.severity]);
  for (const f of bySeverity) {
    const level = LEVEL[f.severity];
    if (!level || f.line === undefined || f.inDiff === false) continue;
    if (counts[level] >= MAX_PER_LEVEL) continue;
    counts[level]++;
    const message = [plain(f.title), f.detail ? plain(f.detail) : '', f.advice ? plain(f.advice) : ''].filter(Boolean).join(' — ');
    out.push(`::${level} file=${escapeProperty(f.file)},line=${f.line},title=${escapeProperty('isobar-pr')}::${escapeData(message)}`);
  }
  return out;
}
```

```ts
export type Format = 'markdown' | 'json' | 'annotations' | 'all';

export class UsageError extends Error {
  override name = 'UsageError';
}

export interface SharedOptions {
  format: Format;
  out: string | undefined;
  failOn: FailOn;
  gateOutput: boolean;
  reportUncalledRoutes: boolean;
}

export function str(v: string | true | undefined): string | undefined {
  return typeof v === 'string' ? v : undefined;
}

export function sharedOptions(args: ParsedArgs): SharedOptions {
  const format = str(args.flags['format']) ?? 'markdown';
  if (!['markdown', 'json', 'annotations', 'all'].includes(format)) throw new UsageError(`--format must be markdown, json, annotations or all, got "${format}"`);

  return {
    format: format as Format,
    out,
    failOn,
    gateOutput: args.flags['gate-output'] === true,
    reportUncalledRoutes: args.flags['report-uncalled-routes'] === true,
  };
```

```ts
import { appendFileSync, mkdirSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import type { Io } from '../cli.js';
import { renderAnnotations } from '../report/annotations.js';
import { toJson } from '../report/json.js';
import { headline, renderMarkdown, truncateComment } from '../report/markdown.js';
import type { Report } from '../report/types.js';
import type { Format } from './options.js';

export interface EmitOptions {
  format: Format;
  out: string | undefined;
  gateOutput: boolean;
  durationMs?: number;
}

/** Writes the report in the requested formats and returns the process exit code. */
export function emitReport(report: Report, o: EmitOptions, io: Io): number {
  const truncated = truncateComment(renderMarkdown(report, { durationMs: o.durationMs }));
  if (truncated.truncated) report.meta.truncated = true;
  const markdown = truncated.text;
  const json = toJson(report);
  const annotationLines = renderAnnotations(report);
  const annotations = annotationLines.length ? annotationLines.join('\n') + '\n' : '';

  if (o.out) {
    mkdirSync(o.out, { recursive: true });
    writeFileSync(join(o.out, 'report.md'), markdown);
    writeFileSync(join(o.out, 'report.json'), json);
    writeFileSync(join(o.out, 'annotations.txt'), annotations);
  }
  if (o.format === 'markdown') io.out(markdown);
  else if (o.format === 'json') io.out(json);
  else if (o.format === 'annotations') io.out(annotations);

  if (o.gateOutput) {
    const summary = headline(report).replace(/\s*\n\s*/g, ' ');
    const lines = `gate=${report.gate}\nsummary=${summary}\n` + (o.out ? `report-json=${join(o.out, 'report.json')}\n` : '');
    const target = io.env['GITHUB_OUTPUT'];
```

```ts
import { spawnSync } from 'node:child_process';

export class GitError extends Error {
  override name = 'GitError';
  readonly code = 3;
  constructor(message: string, public readonly stderr: string) {
    super(message);
  }
}

/** Every git call disables path quoting so non-ASCII paths come back raw (the parsers also unquote, as a fallback). */
const GIT_BASE_ARGS = ['-c', 'core.quotePath=false'];

export function git(cwd: string, args: string[]): string {
  const r = spawnSync('git', [...GIT_BASE_ARGS, ...args], { cwd, encoding: 'utf8', maxBuffer: 256 * 1024 * 1024 });
  if (r.error) throw new GitError(`git ${args[0] ?? ''} could not run: ${r.error.message}`, '');
  if (r.status !== 0) throw new GitError(`git ${args.join(' ')} exited ${r.status}`, r.stderr);
  return r.stdout;
}

function tryGit(cwd: string, args: string[]): string | undefined {
  const r = spawnSync('git', [...GIT_BASE_ARGS, ...args], { cwd, encoding: 'utf8' });
  return r.status === 0 ? r.stdout : undefined;
}

/** Resolves a branch name or sha to a commit sha: origin/<ref>, then <ref>, then the raw value. */
export function resolveRef(cwd: string, ref: string): string | undefined {
  for (const candidate of [`refs/remotes/origin/${ref}`, `refs/heads/${ref}`, ref]) {
    const sha = tryGit(cwd, ['rev-parse', '--verify', '--quiet', `${candidate}^{commit}`]);
    if (sha !== undefined) return sha.trim();
  }
  return undefined;
}

export function mergeBase(cwd: string, a: string, b: string): string {
  return git(cwd, ['merge-base', a, b]).trim();
}

export function headSha(cwd: string): string {
  return git(cwd, ['rev-parse', 'HEAD']).trim();
}

export function isShallow(cwd: string): boolean {
  return git(cwd, ['rev-parse', '--is-shallow-repository']).trim() === 'true';
}

export function isDirty(cwd: string): boolean {
  return git(cwd, ['status', '--porcelain', '--untracked-files=all']).trim() !== '';
}

export function listUntracked(cwd: string): string[] {
  return git(cwd, ['ls-files', '--others', '--exclude-standard']).split('\n').filter((l) => l !== '');
}

/** `head` undefined compares against the working tree. */
export function diffNameStatus(cwd: string, base: string, head?: string): string {
  return git(cwd, ['diff', '--name-status', '-M', '--no-color', '--diff-filter=ACDMRT', base, ...(head ? [head] : [])]); // A25: D rows feed Changes.deleted
}

/** Prefixes are pinned so user config (diff.noprefix, diff.srcPrefix) cannot change what the hunk parser strips. */
export function diffHunks(cwd: string, base: string, head?: string): string {
  return git(cwd, ['diff', '-U0', '-M', '--no-color', '--no-ext-diff', '--no-textconv', '--src-prefix=a/', '--dst-prefix=b/', base, ...(head ? [head] : [])]);
}

export function worktreeAdd(cwd: string, dir: string, sha: string): void {
  git(cwd, ['worktree', 'add', '--detach', dir, sha]);
}

export function worktreeRemove(cwd: string, dir: string): void {
  tryGit(cwd, ['worktree', 'remove', '--force', dir]);
  tryGit(cwd, ['worktree', 'prune']);
}
```

```ts
import { spawnSync } from 'node:child_process';
import { existsSync, mkdirSync } from 'node:fs';
import { dirname } from 'node:path';

export const DEFAULT_ISOBAR_VERSION = '0.7.1';

/** Extensions isobar analyzes (JS/TS family, Vue/Svelte/Astro, Python, Go, R, Java, Ruby, HTML, CSS). */
export const ANALYZABLE_EXTENSIONS: ReadonlySet<string> = new Set([
  'js', 'jsx', 'ts', 'tsx', 'mjs', 'cjs', 'mts', 'cts', 'vue', 'svelte', 'astro',
  'py', 'go', 'r', 'rmd', 'qmd', 'java', 'rb', 'html', 'css', 'scss', 'less',
]);

export function isAnalyzable(path: string): boolean {
  const dot = path.lastIndexOf('.');
  if (dot < 0 || dot < path.lastIndexOf('/')) return false;
  return ANALYZABLE_EXTENSIONS.has(path.slice(dot + 1).toLowerCase());
}

export function isExactSemver(v: string): boolean {
  return /^\d+\.\d+\.\d+(-[0-9A-Za-z.-]+)?$/.test(v);
}

export class IsobarError extends Error {
  override name = 'IsobarError';
  constructor(message: string, public readonly stderr: string, public readonly code: 2 | 3 = 3) {
    super(message);
  }
}

export interface IsobarRunOptions {
  dir: string;
  version: string;
  outFile: string;
  scope?: string;
  timeoutMs?: number;
}

/** Runs `npx -y isobar@<version> <dir> --format json -q -o <outFile>`; never runs project code (isobar guarantees that). */
export function runIsobar(o: IsobarRunOptions): void {
  mkdirSync(dirname(o.outFile), { recursive: true });
  const args = ['-y', `isobar@${o.version}`, o.dir, '--format', 'json', '-q', '-o', o.outFile];
  if (o.scope) args.push('--scope', o.scope);
  const r = spawnSync('npx', args, {
    encoding: 'utf8',
    timeout: o.timeoutMs ?? 120_000,
    maxBuffer: 64 * 1024 * 1024,
    env: { ...process.env, CI: '1' },
  });
  if (r.error) {
    const why = (r.error as NodeJS.ErrnoException).code === 'ETIMEDOUT' ? `timed out after ${(o.timeoutMs ?? 120_000) / 1000} s` : r.error.message;
    throw new IsobarError(`isobar@${o.version} did not finish on ${o.dir}: ${why}`, r.stderr ?? '');
  }
  if (r.status !== 0) throw new IsobarError(`isobar@${o.version} exited ${r.status} on ${o.dir}`, r.stderr ?? '');
  if (!existsSync(o.outFile)) {
    throw new IsobarError(
      `isobar wrote no graph.json for ${o.dir}: the folder looks like a workspace of several projects, which v1 does not support. Point --scope at one project.`,
      r.stderr ?? '',
      2,
    );
  }
}
```

```ts
import { mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join, resolve } from 'node:path';
import { filterChanges, parseChanges, parseHunks } from '../diff/changes.js';
import { isConfigFile } from '../diff/config.js';
import { diffGraphs, emptyReport } from '../diff/index.js';
import { buildIndex } from '../graph/index.js';
import { VersionMismatchError, loadGraph } from '../graph/load.js';
import type { FailOn, Report } from '../report/types.js';
import { diffHunks, diffNameStatus, headSha, isDirty, listUntracked, mergeBase, resolveRef, worktreeAdd, worktreeRemove } from './git.js';
import { isAnalyzable, isExactSemver, runIsobar } from './isobar.js';

export interface CompareOptions {
  dir: string;
  baseRef: string;
  /** 'HEAD' means the working tree, including uncommitted edits. */
  headRef: string;
  isobarVersion: string;
  scope?: string;
  failOn: FailOn;
  reportUncalledRoutes: boolean;
  keepTemp: boolean;
  log: (line: string) => void;
}

export class CompareError extends Error {
  override name = 'CompareError';
  constructor(message: string, public readonly code: 2 | 3) {
    super(message);
  }
}

const FETCH_HINT = 'In GitHub Actions, check out with history:\n  - uses: actions/checkout@v4\n    with: { fetch-depth: 0 }';

export function compare(o: CompareOptions): { report: Report; durationMs: number } {
  const started = Date.now();
  if (!isExactSemver(o.isobarVersion)) {
    throw new CompareError(`--isobar-version must be an exact version such as 0.7.1, got "${o.isobarVersion}"`, 2);
  }
  const dir = resolve(o.dir);

  const baseSha = resolveRef(dir, o.baseRef);
  if (!baseSha) throw new CompareError(`base ref "${o.baseRef}" not found in ${dir}. ${FETCH_HINT}`, 2);
  const headCommitRef = o.headRef === 'HEAD' ? undefined : resolveRef(dir, o.headRef);
  if (o.headRef !== 'HEAD' && !headCommitRef) throw new CompareError(`head ref "${o.headRef}" not found in ${dir}`, 2);
  const headCommit = headCommitRef ?? headSha(dir);
  const base = mergeBase(dir, baseSha, headCommit);

  const changes = filterChanges(parseChanges(diffNameStatus(dir, base, headCommitRef)), o.scope);
  if (!headCommitRef) for (const p of listUntracked(dir)) if (!o.scope || p.startsWith(o.scope.replace(/\/+$/, '') + '/')) changes.changed.add(p);
  changes.hunks = parseHunks(diffHunks(dir, base, headCommitRef));

  const headLabel = headCommitRef ?? (isDirty(dir) ? `${headCommit}-dirty` : headCommit);
  const meta = { baseRef: o.baseRef, baseSha: base, headSha: headLabel, changedFiles: changes.changed.size };
  o.log(`isobar-pr: base ${base.slice(0, 7)} (merge-base of ${o.baseRef}) vs head ${headLabel.slice(0, 13)}, ${changes.changed.size} changed files`);

  if (![...changes.changed].some((p) => isAnalyzable(p) || isConfigFile(p))) {
    o.log('isobar-pr: no analyzable source among the changed files; skipping isobar');
    return { report: emptyReport(meta), durationMs: Date.now() - started };
  }

  const tmp = mkdtempSync(join(tmpdir(), 'isobar-pr-'));
  const baseDir = join(tmp, 'base');
  let headDir = dir;
  let headWorktree: string | undefined;
  try {
    worktreeAdd(dir, baseDir, base);
    if (headCommitRef) {
      headWorktree = join(tmp, 'head');
      worktreeAdd(dir, headWorktree, headCommitRef);
      headDir = headWorktree;
    }
    const baseOut = join(tmp, 'base-out', 'graph.json');
    const headOut = join(tmp, 'head-out', 'graph.json');
    o.log(`isobar-pr: isobar@${o.isobarVersion} on base…`);
    runIsobar({ dir: baseDir, version: o.isobarVersion, outFile: baseOut, scope: o.scope });
    o.log(`isobar-pr: isobar@${o.isobarVersion} on head…`);
    runIsobar({ dir: headDir, version: o.isobarVersion, outFile: headOut, scope: o.scope });

    const baseIndex = buildIndex(loadGraph(baseOut, 'base'));
    const headIndex = buildIndex(loadGraph(headOut, 'head'));
    if (baseIndex.toolVersion !== headIndex.toolVersion) throw new VersionMismatchError(baseIndex.toolVersion, headIndex.toolVersion);

    const report = diffGraphs(baseIndex, headIndex, changes, {
      failOn: o.failOn,
      reportUncalledRoutes: o.reportUncalledRoutes,
      baseRef: o.baseRef,
      baseSha: base,
      headSha: headLabel,
    });
    return { report, durationMs: Date.now() - started };
  } finally {
    worktreeRemove(dir, baseDir);
    if (headWorktree) worktreeRemove(dir, headWorktree);
    if (o.keepTemp) o.log(`isobar-pr: kept ${tmp}`);
    else rmSync(tmp, { recursive: true, force: true });
  }
}
```

````markdown
# isobar-pr

**Pressure delta for every pull request.** isobar-pr runs [isobar](https://www.npmjs.com/package/isobar) on a PR's merge base and on the PR, diffs the two maps, and tells reviewers what the PR did to the codebase's pressure: complexity limits crossed, hotspots touched, conventions broken, new security warnings, circular imports, HTTP calls with no route — and what got better.

Deterministic. No configuration. No LLM, no API keys. The code never leaves the runner.

## In a workflow

```yaml
name: isobar-pr
on:

  pull-requests: write

  cancel-in-progress: true

```

The action posts one sticky comment per PR (edited in place on every push), inline annotations on the changed lines, and the same report as the job summary. With `fail-on` set, it also fails the check.

| --- | --- | --- |
| `base-ref` | PR base branch | Branch to diff against |
| `fail-on` | `none` | `none`, `serious-security`, `limit-crossed` or `any` |
| `isobar-version` | `0.7.1` | Exact isobar version, used on both sides |
| `scope` | | Only analyze this sub-folder (monorepos) |
| `comment` / `annotations` | `true` | Turn either output off |
| `report-uncalled-routes` | `false` | Also report new routes no client in this repo calls |
| `github-token` | `github.token` | Token for the comment |

## On your laptop

```bash
npx isobar-pr compare --base-ref main
```

Prints the same Markdown in a few seconds. Head is your working tree, so you can preview the comment before pushing. `isobar-pr diff --base a.json --head b.json --changes files.txt` diffs two existing `graph.json` files.

## What it reports

Only deltas that touch files the PR changed:

- **Crossed a limit or got slower** — cognitive / cyclomatic complexity, nesting, length, parameters (isobar's limits), time-complexity class, and new performance issues (N+1, await in a loop, lookup in a loop) with isobar's refactor advice.
- **Hotspot touched** — the file is one of the base branch's ten hotspots (complexity × churn), with how many tests import it.
- **Convention broken** — a convention the codebase follows in 75 % or more of cases, with the example file to copy.
- **New security warning** — isobar's security scan (SQL built by string concatenation, tokens in localStorage, TLS checks off, …).
- **Circular import** — new or grown cycles.
- **HTTP contract** — in a repo that serves its own routes, calls that no route answers. In a frontend-only or backend-only repo, one info line instead.
- **Improved** — the same signals in the other direction.

Everything else that was already there is listed in a collapsed footer.

## How it works

1. `BASE = git merge-base origin/<base-ref> HEAD`. On `pull_request` events HEAD is the merge commit, so the diff is exactly the PR's effect.
2. `git worktree add` at BASE; `npx isobar@<pinned>` on both trees (about 3 s each on 800 files).
3. Pure diff of the two `graph.json` files, keyed by file + function name (renames followed), restricted to the PR's changed files and lines.
4. Markdown, `::warning` annotations, stable JSON.

## Limits

- One project per repo in v1; use `scope` for monorepos. Folders of several projects are refused.
- Cross-repo API contracts (separate frontend and backend repos) are not matched.
- Linux and macOS runners.
- Fork PRs get annotations and the summary; the comment needs a token with write access.
````
